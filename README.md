# SparkCoding 星火编程
> 专注计算编程基础入门分享
> 以练为学 | 在线编程闯关 & 即时评测平台
🔗 在线站点：https://sparkcoding.cn

SparkCoding 是一套关卡式编程学习平台，主打**边学边练、提交即判**，不用本地配置环境，浏览器直接写代码、在线评测，自动反馈错误与预期结果。
同时覆盖青少年GESP考级、计算机基础、后端开发、面试八股，适合多类编程学习者。

## ✨ 核心特点
- 🧩 关卡式学习：解锁式进度，循序渐进，记录学习轨迹
- ⚡ 在线即时评测：C/C++/Python/Java/JS/SQL 等在线编译判题
- 📚 课程双线：成人计算机学习 + 青少年GESP C++考级训练
- 🆓 免费模块：计算机通识、Linux Bash、设计模式、WebSocket、HTML+CSS+Vue入门等
- 💎 会员进阶：数据结构算法、DDD、高可用架构、MySQL/Redis/MQ、K8s、GESP全套真题训练

## 📖 课程目录
### 编程语言
C / C++ / Python / Java / HTML+CSS+JS / Vue3 / 大模型Python实践

### 计算机基础（面试/考研408向）
计算机通识、计算机网络、操作系统、数据结构与算法、Linux & Bash、设计模式、SOLID、DDD

### 后端 & 中间件
SQL、MySQL、Redis、MongoDB、消息队列、缓存体系、WebSocket、微服务、Docker / K8s、高可用架构

### 青少年考级
GESP C++ 一级 ~ 四级，配套知识点、练习题、模拟真题

## 👥 适合人群
- 计算机学生：期末复习、考研408、打基础刷题
- 求职后端：面试八股、算法、中间件复习
- 零基础转码：从通识、前端、Python入门
- 青少年 & 家长：备考 CCF GESP C++等级考试
